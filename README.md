# Sausan Berliana Arrizqi — Portfolio Website

Personal portfolio website built from scratch with vanilla HTML, CSS, and JavaScript.

🔗 **Live Demo:** 

---

## Features

- Project cards with category filter (All / ML / Web / UI/UX)
- Project modal with image gallery, tech stack, and key results
- Smooth scroll navigation with active link detection
- Responsive design for mobile and desktop
